# 문제 정의서 — 자가 촬영 상품 사진 배경/조명 정제 PoC

## 도메인 설명
1688에서 옥 지압봉을 소싱해 "효도 용돈박스" 형태로 리패키징한 뒤 쿠팡 등에 판매할 예정. 완성된 리패키징 박스는 직접 촬영해 상세페이지에 쓸 계획. 용돈박스에 실제로 결합해 팔리는 상품 구성 자체는 별도로 시장 조사 중이며(지압봉으로 한정하지 않고 화장품·건강식품·생활용품 등 결합상품 전체로 조사 범위를 넓혀 진행 — 자세한 내용은 `hyodo-gift-mvp` 프로젝트 참고), 이 PoC는 그중 완성된 리패키징 박스를 촬영해 상세페이지용으로 다듬는 단계를 다룬다.

## 현재의 문제
스튜디오 장비 없이 집(거실/방/부엌/욕실/야외 등)에서 상품을 직접 촬영하면 배경이 지저분하거나 조명이 고르지 않아 그대로 상세페이지에 쓰기 어려움. 지금은 이런 사진을 포토샵 등으로 수작업 보정(배경 정리, 조명·그림자 보정)하거나, 아예 마음에 드는 구도의 사진을 포기해야 해서 시간이 많이 들고 촬영-보정 반복 속도가 느려짐.

(초기에는 "알리바바/1688 소싱 이미지의 워터마크·중국어 텍스트 제거"로 문제를 정의했으나, 완성 상품은 소싱 이미지를 재활용하지 않고 직접 촬영한다는 점이 확인되어 위와 같이 재정의함.)

## 개선 가설
rembg로 촬영 이미지에서 상품 영역만 분할하고, Diffusion inpainting으로 그림자·잔여 배경 요소를 자연스럽게 제거한 뒤, 분리된 상품을 표준 흰색/스튜디오 배경 위에 합성하면, 별도 스튜디오 장비나 수작업 보정 없이도 상세페이지에 바로 쓸 수 있는 수준의 정제된 이미지를 얻을 수 있을 것.

**파이프라인:** 촬영 이미지 → rembg(상품 영역 분할) → Diffusion inpainting(그림자·잔여물 제거) → 흰/스튜디오 배경 합성 → 정제된 상세페이지용 이미지

## 대상 사용자
본인(효도 용돈박스 상품 촬영 및 상세페이지 준비 담당자). 스튜디오 없이 자가 촬영으로 상세페이지를 준비하는 1인 셀러·소규모 이커머스 운영자에게도 적용 가능.

## 성공 기준
- 배경/그림자 잔여물이 눈에 띄게 남아있는 결과물 비율: N장 중 잔여물 없는 비율 80% 이상
- 수작업 포토샵 보정 대비 이미지 1장당 처리 시간 단축 폭
- 합성 결과가 부자연스럽지 않아 별도 수정 없이 바로 쓸 수 있는 이미지 비율
